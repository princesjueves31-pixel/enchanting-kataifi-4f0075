MSU-MCEST AR Campus Guide

Main pages:
- index.html: choose Campus Tour or Navigation
- tour.html: 3D campus tour
- navigation.html: camera view, marker scan, GPS tracking, compass arrow
- markers.html: printable QR markers for buildings/corners
- feedback.html: student/guest feedback form
- admin.html: database-backed building, marker, route, and feedback management

Database setup for Chapter 3 / phpMyAdmin:
1. Open phpMyAdmin.
2. Import:
   database/ar_campus.sql
3. Confirm the database name is:
   ar_campus
4. Default admin account:
   admin / admin123

How to run on this computer with PHP/MySQL:
1. Start XAMPP Apache and MySQL.
2. This computer is wired through:
   C:\xamppaki\htdocs\campus_tour -> C:\Users\user\OneDrive\campus_tour
   If that link is missing, recreate it or copy this folder to the XAMPP htdocs folder.
3. Open:
   http://localhost/campus_tour/index.html
4. The database must be imported as:
   ar_campus

How to run as static frontend only:
1. Open a terminal in this folder.
2. Run:
   py -m http.server 8090 --bind 127.0.0.1
3. Open:
   http://127.0.0.1:8090/index.html
4. In this mode the PHP API is unavailable. Use XAMPP for admin/building/database features.

How to run on a phone:
- Camera, GPS, and compass need a secure context.
- Use an HTTPS host such as GitHub Pages, Netlify, Vercel, or a school HTTPS server.
- Print the QR markers from markers.html and place each marker at its matching building/corner.

Navigation flow:
1. Open navigation.html from localhost or HTTPS.
2. Allow camera, location, and compass permissions.
3. Choose a start and destination.
4. Follow the single AR arrow.

Marker payload format:
- msu-mcest:gate
- msu-mcest:admin
- msu-mcest:dcs
- msu-mcest:dhess
- msu-mcest:secondary
